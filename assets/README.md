# DIH Asset Library

## Official mascot IP

The current DIH website uses one official mascot IP only.

- File: `dih_mascot_official.webp`
- Visual identity: brown beaver, cream muzzle, black sunglasses, black hoodie and yellow hard hat.
- The mascot has no individual character name.
- There is no three-character group or separate named character roster.
- Alternate poses or visual treatments must remain the same single IP and follow the approved design.

## Token artwork

- `token-dayone-coin-front.webp` is the current DayOne coin artwork used by the website.

Only production-ready assets used by the current website are kept in this directory. Unused legacy backgrounds, alternate character concepts and the back-side coin artwork have been removed.
