# $DayOne — V2 Website

Advanced static website build following the locked V2 narrative:

Navigation → Hero → Memecoin → Home Base → Still Building → Community → Token → Build Log → Control Board → Meet the Builders → Contract → Social → FAQ → Meta → Footer.

## Identity
Visible brand identity is locked to `$DayOne` / `DayOne`. Do not introduce `DAYONE` or `dayone` as brand casing.

## Configuration
Edit `js/config.js` when the official token contract and token/explorer URLs are available. The three official social URLs are already configured.

## Run
Open `index.html` directly, or serve the folder with any static server.

## Asset approach
The build uses the approved characters, token front/back, token pedestal, logo and controlled environments. CSS supplies scene layering, responsive composition, shadows, overlays and interaction instead of flattening the website into one giant image.
